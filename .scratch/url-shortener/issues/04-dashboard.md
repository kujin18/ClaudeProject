# 04 — 대시보드 조회

**What to build:** 로그인 사용자가 본인이 만든 모든 단축 링크(공개+비공개)를 목록으로 확인한다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] `/dashboard`는 로그인하지 않으면 접근할 수 없다(로그인 페이지로 리다이렉트 등).
- [ ] 대시보드에는 로그인 계정 소유의 삭제되지 않은 모든 링크가 표시된다(공개+비공개 모두 포함).
- [ ] 각 항목에는 원본 URL, 단축 링크 전체 주소, 생성일, 클릭 수가 표시된다.
- [ ] 다른 계정이 만든 링크는 표시되지 않는다.
