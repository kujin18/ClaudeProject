# 02 — URL 단축 링크 생성

**What to build:** 로그인한 사용자가 원본 URL을 입력해 단축 링크(`{handle}/{domainPrefix}/{alias}`)를 생성한다. 도메인 축약어는 자동 추출되며 사용자가 덮어쓸 수 있고, 별칭은 사용자가 직접 정한다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 로그인 사용자가 원본 URL을 입력하면 호스트에서 TLD/흔한 서브도메인(`www` 등)을 제거한 메인 라벨이 도메인축약어 기본값으로 자동 채워진다.
- [ ] 사용자는 자동 채워진 도메인축약어를 직접 수정할 수 있다.
- [ ] 사용자는 별칭을 직접 입력해야 하며, 시스템이 자동 생성하지 않는다.
- [ ] `(계정, 도메인축약어, 별칭)` 조합이 이미 사용 중(삭제되지 않은 레코드 기준)이면 에러를 반환하고 다른 값을 입력하도록 안내한다.
- [ ] 생성된 `ShortLink`는 원본 URL, 도메인축약어, 별칭이 이후 수정 불가능하다.
- [ ] 이미 단축한 적 있는 원본 URL이라도 다른 별칭으로 다시 단축할 수 있다(원본 URL 자체엔 유일성 제약 없음).
- [ ] 생성 직후 사용자에게 완성된 단축 링크(`{handle}/{domainPrefix}/{alias}`)가 표시된다.
