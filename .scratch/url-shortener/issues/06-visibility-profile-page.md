# 06 — 공개/비공개 전환 & 프로필 페이지

**What to build:** 링크마다 공개/비공개 상태를 관리하고(기본 비공개), 계정 핸들 기반 프로필 페이지에서 공개 링크만 누구나 볼 수 있다.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 새로 생성된 링크는 기본적으로 비공개 상태다.
- [ ] 대시보드에서 각 링크의 공개/비공개 상태를 토글할 수 있다.
- [ ] `GET /{handle}`은 로그인 없이 누구나 접근 가능하다.
- [ ] 프로필 페이지에는 해당 계정의 공개 상태이며 삭제되지 않은 링크만 표시된다.
- [ ] 비공개 링크는 프로필 페이지에 노출되지 않는다.
- [ ] 존재하지 않는 핸들로 프로필 페이지에 접근하면 404를 반환한다.
