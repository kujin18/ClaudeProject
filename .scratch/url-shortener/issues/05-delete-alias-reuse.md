# 05 — 단축 링크 삭제 & 별칭 재사용

**What to build:** 대시보드에서 링크를 소프트 삭제할 수 있고, 삭제된 링크는 목록과 리다이렉트에서 사라지며, 같은 별칭을 계정 내에서 다시 쓸 수 있다.

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 대시보드의 각 링크에 삭제 버튼이 있고, 본인 소유 링크만 삭제할 수 있다.
- [ ] 삭제는 소프트 삭제로 처리되며 레코드는 DB에 남는다.
- [ ] 삭제된 링크는 대시보드 목록에 더 이상 나타나지 않는다.
- [ ] 삭제된 링크의 경로로 접속하면 404를 반환한다.
- [ ] 삭제된 (도메인축약어, 별칭) 조합은 같은 계정에서 새 원본 URL에 다시 배정할 수 있다.
