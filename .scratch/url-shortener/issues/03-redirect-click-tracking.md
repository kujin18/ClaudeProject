# 03 — 단축 링크 리다이렉트 & 클릭 집계

**What to build:** 단축 링크 경로에 접속하면 원본 URL로 302 리다이렉트되고, 매 클릭마다 해당 링크의 클릭 수가 증가한다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] `GET /{handle}/{domainPrefix}/{alias}` 요청 시 활성 상태인 링크라면 HTTP 302로 원본 URL로 리다이렉트한다.
- [ ] 존재하지 않거나 삭제된 링크에 접속하면 404를 반환한다.
- [ ] 요청 성공(리다이렉트)마다 해당 `ShortLink`의 클릭 수가 1 증가한다.
- [ ] 로그인하지 않은 사용자도 리다이렉트를 사용할 수 있다(공개/비공개와 무관).
